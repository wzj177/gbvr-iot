# GB28181 预置位和 2022 新功能 - 实现总结

## ✅ 已完成的工作

### 1. 客户端 SDK (Gb28181Client.php)
添加了 3 个新方法:
```php
// 预置位控制
presetControl(deviceId, channelId, action, presetId)
  - action: 'set' | 'call' | 'delete'
  - presetId: 1-255

// 设备升级 (GB28181-2022)
deviceUpgrade(deviceId, manufacturer, firmware)
  - 返回: ['success', 'session_id', 'sn']

// 图像抓拍 (GB28181-2022)
snapshot(deviceId, channelId, imageFormat)
  - imageFormat: 'JPEG' | 'PNG' | 'BMP'
  - 返回: ['success', 'session_id', 'sn', 'image_format']
```

### 2. 业务层 (Gb28181Service.php)
添加了 5 个新方法:
```php
presetSet(deviceId, channelId, presetId)
presetCall(deviceId, channelId, presetId)
presetDelete(deviceId, channelId, presetId)
deviceUpgrade(deviceId, manufacturer, firmware)
snapshot(deviceId, channelId, imageFormat)
```

### 3. 网关命令处理 (CommandDispatcher.php)
添加了命令处理:
```php
// 新增 action 类型
- 'preset_set'       → handlePresetSet()
- 'preset_call'      → handlePresetCall()
- 'preset_delete'    → handlePresetDelete()
- 'device_upgrade'   → handleDeviceUpgrade()
- 'snapshot'         → handleSnapshot()

// 辅助方法
- buildPresetCommand(action, presetId)  // 构建预置位命令
```

**预置位命令格式:**
```
A5 0F 01 [指令码] 00 [预置位ID] 00 [校验码]

0x81: 设置预置位
0x82: 调用预置位
0x83: 删除预置位

示例: 设置预置位5 → A50F018100050088
```

### 4. 网关通知处理 (GB28181Handler.php)
添加了 MediaStatus 通知处理:
```php
handleNotify()
  ↓ 解析 CmdType
  ↓ if (CmdType === 'MediaStatus')
  ↓ handleMediaStatus()

handleMediaStatus()
  - SnapshotComplete: 抓拍完成通知 → postTask('snapshot_complete')
  - Keepalive: 媒体流心跳 → postTask('media_status')
```

### 5. 测试工具 (GB28181Test.php)
添加了 3 个新菜单:
```

```

## 🔄 数据流程

### 预置位操作
```
PHP应用
  ↓ $gb28181->presetSet($deviceId, $channelId, 5)
Gb28181Service
  ↓ $this->getGb28181Client()->presetControl($deviceId, $channelId, 'set', 5)
Gb28181Client  
  ↓ Redis::lPush('gb28181:commands', json_encode([
      'action' => 'preset_set',
      'params' => ['preset_id' => 5]
    ]))
GB28181Handler (Long Task Worker)
  ↓ RedisSubscriber->processCommand()
  ↓ CommandDispatcher->dispatch()
  ↓ handlePresetSet()
  ↓ buildPresetCommand('set', 5) → A50F018100050088
  ↓ QuerySender->ptzControl($targetUri, $channelId, 'A50F018100050088')
ExoSip
  ↓ sendMessage(MESSAGE + PTZCmd XML)
设备
  → 200 OK
```

### 图像抓拍 + 通知
```
PHP应用
  ↓ $gb28181->snapshot($deviceId, $channelId, 'JPEG')
Gb28181Client
  ↓ Redis::lPush('gb28181:commands', json_encode([
      'action' => 'snapshot',
      'params' => ['session_id' => '...', 'image_format' => 'JPEG']
    ]))
CommandDispatcher
  ↓ handleSnapshot()
  ↓ sipServer->sendMessage(Snapshot XML)
设备
  → 200 OK
  → 抓拍处理...
  → NOTIFY: MediaStatus (SnapshotComplete)
GB28181Handler
  ↓ handleNotify()
  ↓ handleMediaStatus()
  ↓ postTask('snapshot_complete', [
      'device_id' => '...',
      'session_id' => '...',
      'file_url' => 'http://192.168.1.73/snapshot/image.jpg'
    ])
Hook API
  ↓ 接收推送
  ↓ 下载图片: file_get_contents($fileUrl)
  ↓ 保存到存储
```

## ⚠️ 重要提示

1. **预置位编号**: 范围 1-255，需要设备支持
2. **设备升级**: 设备会注销→升级→重新注册，视频流会中断
3. **图像抓拍**: 需要设备支持 GB28181-2022，图片URL有效期可能有限
4. **SessionID**: 抓拍和升级的 SessionID 在请求和响应中必须一致
5. **Hook API**: 需要配置正确的推送地址以接收 MediaStatus 通知
