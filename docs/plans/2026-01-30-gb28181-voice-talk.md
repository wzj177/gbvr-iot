# GB28181 语音对讲实现计划

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 实现GB28181语音对讲功能，支持前端通过WebRTC推送音频到ZLM，ZLM转发到GB28181设备。

**Architecture:** 前端先调用API获取推流地址，使用WebRTC推流到ZLM，ZLM通过on_publish Hook通知API，API发送INVITE到设备，设备回复后ZLM开始转发RTP到设备。

**Tech Stack:** PHP 8.2, ExoSip扩展, ZLMediaKit HTTP API, Redis队列, MySQL, WebRTC

---

## 正确的流程图

```
用户 → 前端: 点击"语音对讲"
  ↓
前端 → API: GET /api/v2/gb28181/broadcast/{deviceId}/{channelId}
  ↓
API → 数据库: 创建会话记录（status=waiting_stream）
  ↓
API → 前端: 返回推流地址（webrtc://..., rtsp://..., rtmp://...）
  ↓
前端 → API: GET /api/user/info (获取 pushKey)
  ↓
前端 → 前端: 计算签名 sign=MD5(pushKey)
  ↓
前端 → ZLM: WebRTC 推流（麦克风音频 + sign）
  ↓
ZLM → API: Hook on_publish (流到达通知)
  ↓
API → 数据库: 更新会话（status=stream_arrived）
  ↓
API → 网关: 发送 voice_invite 命令
  ↓
网关 → 设备: INVITE (s=Talk, recvonly, PCMA/8000)
  ↓
设备 → 网关: 200 OK (设备接收IP:Port)
  ↓
网关 → API: Hook voice_established
  ↓
API → ZLM: startSendRtp (开始转发到设备)
  ↓
ZLM → 设备: RTP 音频流
  ↓
用户停止推流
  ↓
ZLM → API: Hook on_unpublish
  ↓
API → 网关: voice_bye 命令
  ↓
网关 → 设备: BYE
  ↓
设备 → 网关: 200 OK
```

**Step 1: 创建 Controller**

```php
<?php

namespace app\api\v2\controller;

use app\api\BaseController;use CoreW\Business\CommonBizException;use CoreW\Business\Devices\Service\VoiceTalkService;use support\Request;

/**
 * GB28181 语音对讲/广播 API
 */
class GB28181BroadcastController extends BaseController
{
    protected function getVoiceTalkService(): VoiceTalkService
    {
        return $this->createService('GB:VoiceTalkService');
    }

    /**
     * 获取语音对讲推流地址
     * GET /api/v2/gb28181/broadcast/{deviceId}/{channelId}
     *
     * 返回多种协议的推流地址，供前端选择使用
     */
    public function broadcast(Request $request, $deviceId, $channelId): \support\Response
    {
        $mode = $request->get('mode', 'talk'); // talk=对讲, broadcast=广播
        $timeout = (int) $request->get('timeout', 30);

        // 参数验证
        if (empty($deviceId) || empty($channelId)) {
            throw CommonBizException::ERROR_PARAMETER_MISSING();
        }

        if (!in_array($mode, ['talk', 'broadcast'])) {
            throw CommonBizException::ERROR_PARAMETER();
        }

        // 检查是否已有活动会话
        $existingSession = $this->getVoiceTalkService()
            ->getVoiceTalkDao()
            ->getByDeviceAndChannel($deviceId, $channelId);

        if ($existingSession && in_array($existingSession['status'], ['waiting_stream', 'stream_arrived', 'inviting', 'established'])) {
            // 返回现有会话的推流地址
            $streamInfo = $this->getVoiceTalkService()->buildStreamInfo(
                $existingSession['stream'],
                $mode
            );
            return $this->createSuccessJsonResponse([
                'session_id' => $existingSession['id'],
                'streamInfo' => $streamInfo,
                'codec' => 'PCMA',
                'app' => $mode,
                'stream' => str_replace($mode . '/', '', $existingSession['stream']),
                'status' => $existingSession['status'],
            ]);
        }

        // 创建新会话并返回推流地址
        $result = $this->getVoiceTalkService()->prepareTalk(
            $deviceId,
            $channelId,
            $mode,
            $timeout
        );

        return $this->createSuccessJsonResponse($result);
    }

    /**
     * 停止语音对讲
     * POST /api/v2/gb28181/broadcast/stop
     */
    public function stop(Request $request): \support\Response
    {
        $sessionId = (int) $request->post('session_id');

        if ($sessionId <= 0) {
            throw CommonBizException::ERROR_PARAMETER_MISSING();
        }

        $this->getVoiceTalkService()->stopVoiceTalk($sessionId);

        return $this->createSuccessJsonResponse(null, '语音对讲已停止');
    }

    /**
     * 查询语音对讲会话
     * GET /api/v2/gb28181/broadcast/session/{id}
     */
    public function session(Request $request, $id): \support\Response
    {
        $id = (int) $id;
        $session = $this->getVoiceTalkService()->getVoiceTalkDao()->get($id);

        if (!$session) {
            return $this->createErrorJsonResponse('会话不存在', null, -1, 404);
        }

        return $this->createSuccessJsonResponse($session);
    }
}
```

**Step 3: 创建 Service**

```php
<?php

namespace CoreW\Business\GB\Service;

use CoreW\Business\CommonBizException;use CoreW\Sdk\ZLMediaKit\ZLMClient;use support\Log;

class VoiceTalkService
{
    protected function getVoiceSessionDao(): \CoreW\Business\Devices\Dao\VoiceSessionDao
    {
        return $this->createDao('GB:VoiceSessionDao');
    }

    protected function getZlmClient(): ZLMClient
    {
        return $this->getBiz()->offsetGet('zlm_sdk');
    }

    protected function getGb28181Service(): Gb28181Service
    {
        return $this->createService('GB:Gb28181Service');
    }

    /**
     * 准备语音对讲（前端获取推流地址时调用）
     *
     * 使用独立的 gv_gb28181_voice_sessions 表
     */
    public function prepareBroadcast(string $deviceId, string $channelId, string $mode = 'talk', int $timeout = 30): array
    {
        // 生成会话ID和流ID
        $sessionId = $this->generateSessionId();
        $streamId = "{$deviceId}_{$channelId}";
        $ssrc = sprintf('%08x', rand(1, 0xFFFFFFFF));

        // 检查是否已有活动会话
        $existing = $this->getVoiceSessionDao()->getByDeviceAndChannel($deviceId, $channelId);
        if ($existing && in_array($existing['status'], ['waiting_stream', 'stream_arrived', 'established'])) {
            // 返回现有会话的推流地址
            return [
                'session_id' => $existing['session_id'],
                'streamInfo' => $this->buildStreamInfo($existing['stream'], $mode),
                'codec' => 'PCMA',
                'app' => $mode,
                'stream' => str_replace($mode . '/', '', $existing['stream']),
                'status' => $existing['status'],
            ];
        }

        // 创建会话记录
        $session = [
            'session_id' => $sessionId,
            'device_id' => $deviceId,
            'channel_id' => $channelId,
            'stream' => "{$mode}/{$streamId}",
            'ssrc' => $ssrc,
            'mode' => $mode,
            'status' => 'waiting_stream',
            'created_at' => date('Y-m-d H:i:s'),
            'updated_at' => date('Y-m-d H:i:s'),
        ];

        $id = $this->getVoiceSessionDao()->create($session);

        // 构建推流地址信息
        $streamInfo = $this->buildStreamInfo("{$mode}/{$streamId}", $mode);

        Log::channel('sip')->info('Voice broadcast prepared', [
            'device_id' => $deviceId,
            'channel_id' => $channelId,
            'session_id' => $sessionId,
            'stream' => "{$mode}/{$streamId}",
        ]);

        return [
            'session_id' => $sessionId,
            'streamInfo' => $streamInfo,
            'codec' => 'PCMA',
            'app' => $mode,
            'stream' => $streamId,
            'status' => 'waiting_stream',
        ];
    }

    private function generateSessionId(): string
    {
        return md5(uniqid('voice_', true));
    }

    /**
     * 构建推流地址信息
     *
     * 返回多种协议的推流地址供前端选择
     */
    public function buildStreamInfo(string $stream, string $mode = 'talk'): array
    {
        $zlmConfig = config('zlm');
        $zlmIp = $zlmConfig['local_ip'] ?? '127.0.0.1';
        $zlmHttpPort = $zlmConfig['http_port'] ?? 80;
        $zlmRtspPort = $zlmConfig['rtsp_port'] ?? 554;
        $zlmRtmpPort = $zlmConfig['rtmp_port'] ?? 1935;
        $zlmRtcPort = $zlmConfig['rtc_port'] ?? 8443;

        $appStream = explode('/', $stream);
        $app = $appStream[0] ?? $mode;
        $streamId = $appStream[1] ?? '';

        return [
            'app' => $app,
            'stream' => $streamId,
            'rtc' => "webrtc://{$zlmIp}:{$zlmRtcPort}/{$app}/{$streamId}",
            'rtcs' => "webrtcs://{$zlmIp}:{$zlmRtcPort}/{$app}/{$streamId}",
            'rtsp' => "rtsp://{$zlmIp}:{$zlmRtspPort}/{$app}/{$streamId}",
            'rtmp' => "rtmp://{$zlmIp}:{$zlmRtmpPort}/{$app}/{$streamId}",
        ];
    }

    /**
     * 处理前端推流到达（on_publish Hook）
     *
     * 前端开始推流后调用，此时发送INVITE到设备
     */
    public function handleStreamPublished(string $app, string $streamId): bool
    {
        if ($app !== 'talk' && $app !== 'broadcast') {
            return false; // 只处理对讲/广播应用
        }

        $stream = "{$app}/{$streamId}";

        // 查找会话
        $session = $this->getVoiceTalkDao()->getByStream($stream);
        if (!$session) {
            Log::channel('sip')->warning('Voice stream published but no session found', [
                'stream' => $stream,
            ]);
            return false;
        }

        // 更新会话状态
        $this->getVoiceTalkDao()->updateStatus($session['id'], 'stream_arrived');

        // 发送 INVITE 到设备
        $gb28181Service = $this->getGb28181Service();
        $result = $gb28181Service->startVoiceTalk($session['device_id'], $session['channel_id'], [
            'mode' => $session['mode'],
            'ssrc' => $session['ssrc'],
            'session_id' => $session['id'],
        ]);

        Log::channel('sip')->info('Voice INVITE sent after stream published', [
            'device_id' => $session['device_id'],
            'channel_id' => $session['channel_id'],
            'stream' => $stream,
        ]);

        return true;
    }

    /**
     * 处理会话建立回调（来自网关）
     */
    public function handleSessionEstablished(array $data): bool
    {
        $deviceId = $data['device_id'];
        $channelId = $data['channel_id'];
        $dialogId = $data['dialog_id'];
        $callId = $data['call_id'];
        $deviceIp = $data['device_ip'] ?? null;
        $devicePort = $data['device_port'] ?? null;

        // 查找会话
        $session = $this->getVoiceTalkDao()->getByDeviceAndChannel($deviceId, $channelId);
        if (!$session) {
            return false;
        }

        // 从 ZLM 获取 RTP 端口
        $zlmClient = $this->getZlmClient();
        $streamId = str_replace('talk/', '', $session['stream']);
        $streamId = str_replace('broadcast/', '', $streamId);

        // 调用 ZLM openRtpServer 获取端口
        $portResult = $zlmClient->openRtpServer([
            'stream' => $streamId,
            'enable_tcp' => true,
        ]);

        if ($portResult['code'] != 0) {
            Log::channel('sip')->error('Failed to open RTP server', [
                'stream' => $session['stream'],
            ]);
            $this->getVoiceTalkDao()->updateStatus($session['id'], 'failed');
            return false;
        }

        $zlmPort = $portResult['data']['port'] ?? 0;
        $zlmIp = config('zlm.local_ip') ?? '127.0.0.1';

        // 更新会话
        $this->getVoiceTalkDao()->update($session['id'], [
            'dialog_id' => $dialogId,
            'call_id' => $callId,
            'device_ip' => $deviceIp,
            'device_port' => $devicePort,
            'zlm_port' => $zlmPort,
            'zlm_ip' => $zlmIp,
            'status' => 'established',
            'started_at' => date('Y-m-d H:i:s'),
            'updated_at' => date('Y-m-d H:i:s'),
        ]);

        // 启动 RTP 推流到设备
        $this->startRtpStream(array_merge($session, [
            'zlm_port' => $zlmPort,
            'zlm_ip' => $zlmIp,
            'device_ip' => $deviceIp,
            'device_port' => $devicePort,
        ]));

        Log::channel('sip')->info('Voice session established and RTP started', [
            'device_id' => $deviceId,
            'channel_id' => $channelId,
            'zlm_port' => $zlmPort,
            'device_port' => $devicePort,
        ]);

        return true;
    }

    /**
     * 启动 RTP 推流到设备
     */
    private function startRtpStream(array $session): void
    {
        $zlmClient = $this->getZlmClient();

        $streamId = str_replace('talk/', '', $session['stream']);
        $streamId = str_replace('broadcast/', '', $streamId);

        $zlmClient->startSendRtp([
            'vhost' => '__defaultVhost__',
            'app' => $session['mode'] === 'broadcast' ? 'broadcast' : 'talk',
            'stream' => $streamId,
            'ssrc' => hexdec($session['ssrc']),
            'dst_url' => $session['device_ip'],
            'dst_port' => $session['device_port'],
            'is_udp' => true,
            'pkt_size' => 1400,
        ]);
    }

    /**
     * 停止语音对讲
     */
    public function stopVoiceTalk(int $sessionId): bool
    {
        $session = $this->getVoiceTalkDao()->get($sessionId);
        if (!$session) {
            throw CommonBizException::ERROR_PARAMETER();
        }

        // 发送 BYE
        if (!empty($session['dialog_id'])) {
            $gb28181Service = $this->getGb28181Service();
            $gb28181Service->stopVoiceTalk($session['device_id'], $session['channel_id'], $session['dialog_id']);
        }

        // 停止 ZLM RTP 推流
        if ($session['zlm_port'] > 0) {
            $zlmClient = $this->getZlmClient();
            $zlmClient->stopSendRtp($session['stream']);
        }

        // 更新会话状态
        $this->getVoiceTalkDao()->update($sessionId, [
            'status' => 'ended',
            'ended_at' => date('Y-m-d H:i:s'),
            'updated_at' => date('Y-m-d H:i:s'),
        ]);

        return true;
    }

    /**
     * 处理前端停止推流（on_unpublish Hook）
     */
    public function handleStreamUnpublished(string $app, string $streamId): bool
    {
        if ($app !== 'talk' && $app !== 'broadcast') {
            return false;
        }

        $stream = "{$app}/{$streamId}";

        // 查找会话并结束
        $session = $this->getVoiceTalkDao()->getByStream($stream);
        if ($session && in_array($session['status'], ['stream_arrived', 'inviting', 'established'])) {
            $this->stopVoiceTalk($session['id']);

            Log::channel('sip')->info('Voice session ended due to stream unpublished', [
                'device_id' => $session['device_id'],
                'channel_id' => $session['channel_id'],
            ]);
        }

        return true;
    }

    /**
     * 处理会话结束回调（来自网关BYE）
     */
    public function handleSessionEnded(array $data): bool
    {
        $dialogId = $data['dialog_id'] ?? 0;

        $session = $this->getVoiceTalkDao()->getByDialogId($dialogId);
        if (!$session) {
            return false;
        }

        return $this->stopVoiceTalk($session['id']);
    }
}
```

```php
 * 前端开始推流时触发，此时发送INVITE到设备

private function handleOnPublish(array $body): void
{
    $app = $body['app'] ?? '';
    $stream = $body['stream'] ?? '';

    // 只处理对讲/广播应用
    if ($app !== 'talk' && $app !== 'broadcast') {
        return;
    }

    Log::channel('sip')->info('Voice stream published', [
        'app' => $app,
        'stream' => $stream,
        'ip' => $body['ip'] ?? '',
        'port' => $body['port'] ?? 0,
    ]);

    // 通知业务服务
    $voiceTalkService = $this->createService('GB:VoiceTalkService');
    $voiceTalkService->handleStreamPublished($app, $stream);
}

private function handleOnUnpublish(array $body): void
{
    $app = $body['app'] ?? '';
    $stream = $body['stream'] ?? '';

    if ($app !== 'talk' && $app !== 'broadcast') {
        return;
    }

    Log::channel('sip')->info('Voice stream unpublished', [
        'app' => $app,
        'stream' => $stream,
    ]);

    $voiceTalkService = $this->createService('GB:VoiceTalkService');
    $voiceTalkService->handleStreamUnpublished($app, $stream);
```

```php
public function handleVoiceInvite(array $params): array
{
    $deviceId = $params['device_id'];
    $channelId = $params['channel_id'];
    $mode = $params['mode'] ?? 'talk';
    $ssrc = $params['ssrc'] ?? $this->generateSsrc();

    $device = $this->deviceManager->getDeviceObject($deviceId);
    if (!$device || !$device->isRegistered()) {
        return [
            'success' => false,
            'error' => 'Device not registered',
        ];
    }

    // 获取设备实际地址
    $deviceIp = $device->getReceivedIp() ?? $device->getIp();
    $devicePort = $device->getReceivedPort() ?? $device->getPort();

    // 构建 SIP URI
    $targetUri = "sip:{$channelId}@{$deviceIp}:{$devicePort}";

    // 构建 SDP（此时还没有 ZLM 端口，使用占位符）
    $sdp = $this->buildTalkSdp(
        $this->config['server_id'],
        $deviceId,
        $channelId,
        '0.0.0.0', // 占位符IP，等200 OK后从ZLM获取
        0,          // 占位符端口
        $mode,
        $ssrc
    );

    // 发送 INVITE
    $callId = $this->sipServer->sendInvite($targetUri, $sdp, [
        'Subject' => "{$channelId}:{$ssrc},{$this->config['server_id']}:0",
        'Content-Type' => 'application/sdp'
    ]);

    if ($callId < 0) {
        return [
            'success' => false,
            'error' => 'Failed to send INVITE',
        ];
    }

    // 保存会话信息到 Redis
    $sessionKey = "voice_session:{$deviceId}:{$channelId}";
    $this->redis->setex($sessionKey, 300, json_encode([
        'call_id' => $callId,
        'device_id' => $deviceId,
        'channel_id' => $channelId,
        'mode' => $mode,
        'ssrc' => $ssrc,
        'session_id' => $params['session_id'] ?? null,
        'status' => 'inviting',
        'created_at' => time(),
    ]));

    $this->log("Voice INVITE sent: {$deviceId}/{$channelId}, Call-ID: {$callId}");

    return [
        'success' => true,
        'call_id' => $callId,
        'device_id' => $deviceId,
        'channel_id' => $channelId,
    ];
}

public function handleVoiceBye(array $params): array
{
    $deviceId = $params['device_id'];
    $dialogId = $params['dialog_id'] ?? 0;

    $result = $this->sipServer->sendBye($dialogId);

    if ($result) {
        // 清理 Redis 缓存
        $sessionKey = "voice_session:{$deviceId}:{$params['channel_id']}";
        $this->redis->del($sessionKey);
    }

    return [
        'success' => $result,
        'device_id' => $deviceId,
    ];
}

/**
 * 构建语音对讲 SDP
 */
private function buildTalkSdp(
    string $serverId,
    string $deviceId,
    string $channelId,
    string $zlmIp,
    int $zlmPort,
    string $mode,
    string $ssrc
): string {
    $sessionName = $mode === 'broadcast' ? 'Broadcast' : 'Talk';

    $sdp = "v=0\r\n"
        . "o={$serverId} 0 0 IN IP4 {$zlmIp}\r\n"
        . "s={$sessionName}\r\n"
        . "c=IN IP4 {$zlmIp}\r\n"
        . "t=0 0\r\n"
        . "m=audio {$zlmPort} RTP/AVP 8\r\n"
        . "a=recvonly\r\n"
        . "a=rtpmap:8 PCMA/8000\r\n"
        . "y={$ssrc}\r\n";

    return $sdp;
}

private function generateSsrc(): string
{
    return sprintf('%08x', rand(1, 0xFFFFFFFF));
}
```

```php
private function handleInviteResponse(\SipEvent $event): void
{
    $statusCode = $event->getCode();
    if ($statusCode !== 200) {
        return; // 只处理 200 OK
    }

    $callId = $event->getCallId();
    $dialogId = $event->getDialogId();
    $fromUri = $event->getFromUri();
    $deviceId = $this->extractDeviceId($fromUri);
    $toUri = $event->getToUri();
    $channelId = $this->extractDeviceId($toUri);

    // 解析设备 SDP
    $sdp = $event->getSdp();
    if (!$sdp) {
        $this->log("收到200 OK但无SDP", 'WARNING');
        return;
    }

    // 提取设备音频接收地址
    $deviceIp = $sdp['connection']['addr'] ?? null;
    $devicePort = isset($sdp['medias'][0]) ? $sdp['medias'][0]['port'] : null;

    // 检查是否为语音对讲会话（从Redis查找）
    $sessionKey = "voice_session:{$deviceId}:{$channelId}";
    $sessionData = $this->redis->get($sessionKey);

    if ($sessionData) {
        $session = json_decode($sessionData, true);

        // 更新会话信息
        $session['dialog_id'] = $dialogId;
        $session['device_ip'] = $deviceIp;
        $session['device_port'] = $devicePort;
        $session['status'] = 'established';

        $this->redis->setex($sessionKey, 300, json_encode($session));

        // 发送 ACK
        if ($dialogId > 0) {
            $this->sipServer->sendAck($dialogId);
        }

        // 通知 API 会话已建立
        $this->postTask('voice_established', [
            'device_id' => $deviceId,
            'channel_id' => $channelId,
            'dialog_id' => $dialogId,
            'call_id' => $callId,
            'device_ip' => $deviceIp,
            'device_port' => $devicePort,
            'mode' => $session['mode'] ?? 'talk',
            'ssrc' => $session['ssrc'] ?? '',
            'session_id' => $session['session_id'] ?? null,
            'timestamp' => time(),
        ]);

        $this->log("语音对讲会话已建立: {$deviceId}/{$channelId}");
    } else {
        // 可能是视频会话，保持原有逻辑
        $this->log("INVITE 200 OK: {$deviceId} -> {$channelId}", 'DEBUG');
        if ($dialogId > 0) {
            $this->sipServer->sendAck($dialogId);
        }
    }
}
```

## 注意事项

1. **正确的流程顺序**：前端先推流 → on_publish Hook → 发送 INVITE → 200 OK → 开始转发
2. **SSRC 格式**：GB28181 SSRC 为 8 位十六进制字符串
3. **SDP 格式**：`s=Talk` 表示对讲，`s=Broadcast` 表示广播
4. **音频编码**：使用 PCMA/8000 (G.711 A-law)
5. **媒体模式**：`a=recvonly` 表示设备接收音频
6. **推流地址**：需要返回多种协议（WebRTC, RTSP, RTMP）
7. **签名验证**：使用 MD5(pushKey) 进行推流鉴权
8. **会话状态**：waiting_stream → stream_arrived → inviting → established → ended
