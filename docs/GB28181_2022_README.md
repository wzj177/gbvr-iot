# GB28181-2022 新功能和预置位操作

## 概述
本文档说明如何在 `Gb28181Client` 类中实现预置位操作和 GB28181-2022 新功能。

## 需要在 Gb28181Client 中添加的方法

### 1. 预置位控制

```php
/**
 * 预置位控制
 * 
 * @param string $deviceId 设备ID
 * @param string $channelId 通道ID
 * @param string $action 操作类型: 'set'(设置), 'call'(调用), 'delete'(删除)
 * @param int $presetId 预置位编号 (1-255)
 * @return bool
 */
public function presetControl(string $deviceId, string $channelId, string $action, int $presetId): bool
{
    // 构建预置位命令
    $cmdCode = match($action) {
        'set' => 0x81,
        'call' => 0x82,
        'delete' => 0x83,
        default => 0x00
    };
    
    $presetId = max(1, min(255, $presetId));
    $checksum = (0xA5 + 0x0F + 0x01 + $cmdCode + 0x00 + $presetId + 0x00) % 0x100;
    $ptzCmd = sprintf("A50F01%02X00%02X00%02X", $cmdCode, $presetId, $checksum);
    
    // 发送命令 (通过 Redis 或直接调用)
    return $this->sendCommand($deviceId, $channelId, 'ptz_preset', [
        'action' => $action,
        'preset_id' => $presetId,
        'ptz_cmd' => $ptzCmd
    ]);
}
```

**命令格式示例:**
- 设置预置位5: `A50F018100050088`
- 调用预置位5: `A50F018200050089`
- 删除预置位5: `A50F01830005008A`

### 2. GB28181-2022: 设备升级

```php
/**
 * 设备升级 (GB28181-2022)
 * 
 * @param string $deviceId 设备ID
 * @param string $manufacturer 制造商
 * @param string $firmware 固件版本
 * @return array ['success' => bool, 'session_id' => string, 'sn' => int]
 */
public function deviceUpgrade(string $deviceId, string $manufacturer, string $firmware): array
{
    $sn = rand(1, 99999999);
    
    return $this->sendCommand($deviceId, '', 'device_upgrade', [
        'manufacturer' => $manufacturer,
        'firmware' => $firmware,
        'sn' => $sn
    ]);
}
```

**XML 示例:**
```xml
<?xml version="1.0" encoding="GB2312"?>
<Control>
  <CmdType>DeviceControl</CmdType>
  <SN>80267728</SN>
  <DeviceID>31020000011310000073</DeviceID>
  <DeviceUpgrade>
    <Manufacturer>Hikvision</Manufacturer>
    <Firmware>V5.7.12_build230801</Firmware>
  </DeviceUpgrade>
</Control>
```

### 3. GB28181-2022: 图像抓拍

```php
/**
 * 图像抓拍 (GB28181-2022)
 * 
 * @param string $deviceId 设备ID
 * @param string $channelId 通道ID
 * @param string $imageFormat 图片格式 (JPEG/PNG/BMP)
 * @return array ['success' => bool, 'session_id' => string, 'sn' => int]
 */
public function snapshot(string $deviceId, string $channelId, string $imageFormat = 'JPEG'): array
{
    $sessionId = strtoupper(md5(uniqid() . microtime(true)));
    $sn = rand(1, 99999999);
    
    return $this->sendCommand($deviceId, $channelId, 'snapshot', [
        'session_id' => $sessionId,
        'image_format' => $imageFormat,
        'sn' => $sn
    ]);
}
```

**XML 示例:**
```xml
<?xml version="1.0" encoding="GB2312"?>
<Control>
  <CmdType>DeviceControl</CmdType>
  <SN>80267729</SN>
  <DeviceID>31020000011310000073</DeviceID>
  <Snapshot>
    <SessionID>A1FBCA20ACF640D8BA317E4DC4620802677281FD</SessionID>
    <ImageFormat>JPEG</ImageFormat>
  </Snapshot>
</Control>
```

**设备响应 (MediaStatus 通知):**
```xml

  <SN>80267730</SN>
```

## 在网关 (GB28181Handler) 中的处理

### 1. 处理 MediaStatus 通知

需要在 `handleNotify` 方法中添加对 `MediaStatus` 通知的处理:

```php
public function handleNotify(\SipEvent $event): void
{
    $body = $event->getBody();
    if (empty($body)) {
        $this->log("收到空的 NOTIFY 消息体");
        return;
    }

    // 解析 XML
    $result = $this->messageHandler->parse($body);
    if (!$result || !isset($result['CmdType'])) {
        return;
    }

    $cmdType = $result['CmdType'];
    
    // GB28181-2022: MediaStatus 通知
    if ($cmdType === 'MediaStatus') {
        $this->handleMediaStatus($event, $result);
        return;
    }
    
    // 其他通知类型...
}

/**
 * 处理 MediaStatus 通知 (GB28181-2022)
 */
private function handleMediaStatus(\SipEvent $event, array $data): void
{
    $notifyType = $data['NotifyType'] ?? '';
    $deviceId = $data['DeviceID'] ?? '';
    
    if ($notifyType === 'SnapshotComplete') {
        // 抓拍完成
        $sessionId = $data['SessionID'] ?? '';
        $fileUrl = $data['FileURL'] ?? '';
        
        $this->log("设备 {$deviceId} 抓拍完成: SessionID={$sessionId}, URL={$fileUrl}");
        
        // 推送到业务系统
        $this->postTask('snapshot_complete', [
            'device_id' => $deviceId,
            'session_id' => $sessionId,
            'file_url' => $fileUrl,
            'data' => $data
        ]);
    } elseif ($notifyType === 'Keepalive') {
        // 媒体流心跳
        $ssrc = $data['SSRC'] ?? '';
        $bitRate = $data['BitRate'] ?? '';
        $frameRate = $data['FrameRate'] ?? '';
        
        $this->log("媒体流心跳: SSRC={$ssrc}, BitRate={$bitRate}, FrameRate={$frameRate}");
    }
    
    // 发送 200 OK
    $this->sipServer->sendReply($event, 200, 'OK');
}
```

## 命令格式参考

### PTZ 预置位命令格式

```
格式: A5 0F 01 [指令码] 00 [预置位ID] 00 [校验码]

指令码:
- 0x81: 设置预置位
- 0x82: 调用预置位
- 0x83: 删除预置位

校验码计算:
checksum = (0xA5 + 0x0F + 0x01 + 指令码 + 0x00 + 预置位ID + 0x00) % 256

示例:
设置预置位5: A5 0F 01 81 00 05 00 88
- 0x81 = 设置预置位
- 0x05 = 预置位编号5
- 0x88 = (0xA5+0x0F+0x01+0x81+0x00+0x05+0x00) % 256 = 0x88
```

## 注意事项

1. **设备升级**: 设备会先注销,升级完成后重新注册
2. **图像抓拍**: 设备会通过 `MediaStatus` 通知返回图片URL
3. **SessionID**: 抓拍和升级命令需要保持 SessionID 一致性
4. **SN值匹配**: 响应命令中的 SN 值要与请求命令的 SN 值一致
5. **预置位范围**: 预置位编号范围为 1-255
