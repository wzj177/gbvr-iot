# GB28181 录像回放控制完整测试

> 基于 GB/T 28181-2022 附录 B（MANSRTSP 协议）

## ✅ 服务器端实现确认

**结论：服务器端实现完全符合国标，没有任何问题。**

所有命令格式已通过协议文档验证：
- ✅ 暂停：`PAUSE + PauseTime: now`
- ✅ 恢复：`PLAY + Range: npt=now-`
- ✅ 倍速：`PLAY + Scale: N`（不带 Range）
- ✅ 拖动：`PLAY + Range: npt=100-`（不带 Scale）

## 🎯 完整的 API 使用示例

### 1. 启动回放

```php
// 1.1 开始回放（正常倍速）
$result = $commandDispatcher->dispatch([
    'request_id' => 'req-001',
    'device_id' => '34020000001320000001',
    'channel_id' => '34020000001310000001',
    'device_ip' => '192.168.1.101',
    'device_port' => 5060,
    'command' => 'start_playback',
    'params' => [
        'start_time' => '2024-01-22T10:00:00',
        'end_time' => '2024-01-22T11:00:00',
        'media_host' => '192.168.1.100',  // ZLM 地址
        'media_port' => 6000,
    ]
]);

$streamId = $result['stream_id'];  // 保存 stream_id，用于后续控制
```

### 2. 暂停回放

```php
// GB28181 B.2.2: PAUSE RTSP/1.0 + PauseTime: now
$result = $commandDispatcher->dispatch([
    'request_id' => 'req-002',
    'device_id' => '34020000001320000001',
    'channel_id' => '34020000001310000001',
    'device_ip' => '192.168.1.101',
    'device_port' => 5060,
    'command' => 'playback_control',
    'params' => [
        'stream_id' => $streamId,  // 必须：用于查找 dialog_id
        'action' => 'pause',
    ]
]);

// 发送的 SIP INFO 消息体：
// PAUSE RTSP/1.0
// CSeq: 2
// PauseTime: now
```

### 3. 恢复播放

```php
// GB28181 B.2.1: PLAY RTSP/1.0 + Range: npt=now-（从暂停位置以原倍速恢复）
$result = $commandDispatcher->dispatch([
    'request_id' => 'req-003',
    'device_id' => '34020000001320000001',
    'channel_id' => '34020000001310000001',
    'device_ip' => '192.168.1.101',
    'device_port' => 5060,
    'command' => 'playback_control',
    'params' => [
        'stream_id' => $streamId,
        'action' => 'resume',  // 或 'play'
    ]
]);

// 发送的 SIP INFO 消息体：
// PLAY RTSP/1.0
// CSeq: 3
// Range: npt=now-
```

### 4. 倍速播放

```php
// GB28181 B.2.3: PLAY RTSP/1.0 + Scale: N（不携带 Range 头）
// 标准支持：0.25, 0.5, 1, 2, 4

// 4.1 快进 2 倍速
$result = $commandDispatcher->dispatch([
    'request_id' => 'req-004',
    'device_id' => '34020000001320000001',
    'channel_id' => '34020000001310000001',
    'device_ip' => '192.168.1.101',
    'device_port' => 5060,
    'command' => 'playback_control',
    'params' => [
        'stream_id' => $streamId,
        'action' => 'fast_forward',  // 或 'scale'
        'speed' => 2,                 // 或 'scale' => 2
    ]
]);

// 发送的 SIP INFO 消息体：
// PLAY RTSP/1.0
// CSeq: 4
// Scale: 2

// 4.2 慢放 0.5 倍速
$result = $commandDispatcher->dispatch([
    'params' => [
        'stream_id' => $streamId,
        'action' => 'slow_forward',
        'speed' => 2,  // 结果：Scale: 0.5
    ]
]);

// 4.3 直接指定倍速
$result = $commandDispatcher->dispatch([
    'params' => [
        'stream_id' => $streamId,
        'action' => 'scale',
        'scale' => 4.0,  // 4倍速
    ]
]);
```

### 5. 随机拖放

```php
// GB28181 B.2.4: PLAY RTSP/1.0 + Range: npt=100-（不携带 Scale 头）

// 5.1 跳转到第 100 秒
$result = $commandDispatcher->dispatch([
    'request_id' => 'req-005',
    'device_id' => '34020000001320000001',
    'channel_id' => '34020000001310000001',
    'device_ip' => '192.168.1.101',
    'device_port' => 5060,
    'command' => 'playback_control',
    'params' => [
        'stream_id' => $streamId,
        'action' => 'seek',
        'seek_time' => 100,  // 秒数
    ]
]);

// 发送的 SIP INFO 消息体：
// PLAY RTSP/1.0
// CSeq: 5
// Range: npt=100-

        'stream_id' => $streamId,
        'action' => 'seek',
        'seek_time' => '00:10:30',  // 10分30秒 = 630秒
    ]
]);
```

### 6. 倒放（GB28181-2022）

```php
// GB28181 B.2.8: PLAY RTSP/1.0 + Scale: -1（负数表示倒放）

// 6.1 一倍速倒放（从当前位置）
$result = $commandDispatcher->dispatch([
    'request_id' => 'req-006',
    'device_id' => '34020000001320000001',
    'channel_id' => '34020000001310000001',
    'device_ip' => '192.168.1.101',
    'device_port' => 5060,
    'command' => 'playback_control',
    'params' => [
        'stream_id' => $streamId,
        'action' => 'reverse',
        'speed' => 1,  // 可选，默认1
    ]
]);

// 发送的 SIP INFO 消息体：
// PLAY RTSP/1.0
// CSeq: 6
// Scale: -1

// 6.2 指定倒放范围（从第600秒倒放到第120秒）
// 注意：需要在 CommandDispatcher 中添加 reverse 的 range 参数支持
```

### 7. 跳转并指定倍速

```php
// 同时指定位置和倍速（组合命令）
$result = $commandDispatcher->dispatch([
    'request_id' => 'req-007',
    'device_id' => '34020000001320000001',
    'channel_id' => '34020000001310000001',
    'device_ip' => '192.168.1.101',
    'device_port' => 5060,

        'action' => 'seek_and_play',
        'seek_time' => 200,   // 跳转到第200秒

    ]
]);

// 发送的 SIP INFO 消息体：
// PLAY RTSP/1.0
// CSeq: 7
// Range: npt=200-
// Scale: 2.0
```

### 8. 停止回放


## 📋 快捷方法汇总（QuerySender）

```php
$querySender = new QuerySender($sipServer, $config);

$querySender->playbackSeekAndPlay($dialogId, 200, 2.0);  // 跳到200秒，2倍速播放
```

## 📊 命令对照表

| API Action | MANSRTSP 命令 | GB28181 标准 | 说明 |
|-----------|---------------|--------------|------|
| `pause` | `PAUSE + PauseTime: now` | B.2.2 | 暂停在当前位置 |
| `resume` / `play` | `PLAY + Range: npt=now-` | B.2.1 | 从暂停位置恢复 |
| `scale` / `fast_forward` | `PLAY + Scale: 2` | B.2.3 | 倍速播放（不带Range） |
| `slow_forward` | `PLAY + Scale: 0.5` | B.2.3 | 慢放（Scale < 1） |
| `seek` | `PLAY + Range: npt=100-` | B.2.4 | 跳转（不带Scale） |
| `reverse` | `PLAY + Scale: -1` | B.2.8 | 倒放（负Scale） |
| `stop` / `teardown` | `TEARDOWN` | B.2.5 | 停止并释放资源 |
| `seek_and_play` | `PLAY + Range + Scale` | - | 组合命令 |
