## 1. SIP 基础

### 传输协议
- 支持 UDP / TCP（标准端口 5060）
- 设备注册时携带 `Expires` 头，心跳维持会话

### 关键 SIP 对话标识
| 字段 | 说明 |
|------|------|
| `Call-ID` | 每次 INVITE 唯一，BYE 时相同 |
| `From-tag` | 随机生成 |
| `CSeq` | 每次请求递增 |
| `Via branch` | 随机，每个请求唯一 |

### Content-Type
- 设备控制/查询消息：`Application/MANSCDP+xml`
- SDP 消息：`Application/SDP`
- 回放控制：`Application/MANSRTSP`

## 5. PTZ 控制

### 5.1 SIP MESSAGE 消息体

PTZ 控制通过 `MESSAGE` 方法发送，消息体：

```xml
<?xml version="1.0" encoding="GB2312"?>
<Control>
  <CmdType>DeviceControl</CmdType>
  <SN>123456</SN>
  <DeviceID>34020000001310000001</DeviceID>
  <PTZCmd>A50F0102FF000064</PTZCmd>
  <Info>
    <ControlPriority>5</ControlPriority>
  </Info>
</Control>
```

### 5.2 PTZCmd 字节计算算法

**格式：** 8字节 HEX 字符串（16个十六进制字符）

```
[A5][0F][01][CMD][SPEED_H][SPEED_V][ZOOM][CHECK]
```

| 位置 | 字节 | 说明 |
|------|------|------|
| 0 | `A5` | 固定帧头 |
| 1 | `0F` | 固定 |
| 2 | `01` | 固定 |
| 3 | CMD | 控制指令位（见下） |
| 4 | SPEED_H | 水平速度 0x00~0xFF |
| 5 | SPEED_V | 垂直速度（=水平速度） |
| 6 | `高4位=zoom速度，低4位=0` | 变倍速度 |
| 7 | CHECK | 校验码 |

**CMD 字节位定义：**

| 位 | 含义 |
|----|------|
| bit0 | 右移（leftRight=2） |
| bit1 | 左移（leftRight=1） |
| bit2 | 下移（upDown=2） |
| bit3 | 上移（upDown=1） |
| bit4 | 放大（inOut=2） |
| bit5 | 缩小（inOut=1） |
| bit6~7 | 保留，置0 |

**校验码：**
```
checkCode = (0xA5 + 0x0F + 0x01 + CMD + SPEED_H + SPEED_V + (zoomSpeed & 0xF0)) % 0x100
```

**zoom 速度特殊处理：**
```
if (zoomSpeed > 0 && zoomSpeed < 16):
    zoomSpeed = 16   // 低倍速最小值
字节6 = (zoomSpeed << 4) & 0xF0  // 只取高4位
```

**示例（向右转，速度0xFF，不变倍）：**
```
CMD = 0x01 (bit0=1，右移)
SPEED_H = SPEED_V = 0xFF
ZOOM字节 = 0x00
CHECK = (0xA5+0x0F+0x01+0x01+0xFF+0xFF+0x00) % 0x100 = 0x64
结果：A50F0101FFFF0064
```

**停止命令（所有参数=0）：**
```
A50F010000000000  → CHECK = (0xA5+0x0F+0x01+0+0+0+0) % 0x100 = 0xB5
停止：A50F01000000000B5
```

## 6. 前端扩展指令（FrontEndCommand）

### 6.1 通用指令格式（与PTZ同XML，PTZCmd不同）

```xml
<Control>
  <CmdType>DeviceControl</CmdType>
  <SN>123456</SN>
  <DeviceID>34020000001310000001</DeviceID>
  <PTZCmd>A50F01xx</PTZCmd>
  <Info>
    <ControlPriority>5</ControlPriority>
  </Info>
</Control>
```

### 6.2 FrontEndCmdString 计算

```
[A5][0F][01][CmdCode][Param1][Param2][CombineCode2<<4][CHECK]
```

```
checkCode = (0xA5 + 0x0F + 0x01 + cmdCode + param1 + param2 + (combineCode2 << 4)) % 0x100
```

### 6.3 常用 CmdCode 定义

| CmdCode | 功能 | Param1 | Param2 | CombineCode2 |
|---------|------|--------|--------|--------------|
| `0x03` | 调用预置位 | 预置位编号(1-255) | 0 | 0 |
| `0x01` | 设置预置位 | 预置位编号 | 0 | 0 |
| `0x02` | 删除预置位 | 预置位编号 | 0 | 0 |
| `0x08` | 开始巡航 | 巡航组编号 | 0 | 0 |
| `0x09` | 停止巡航 | 巡航组编号 | 0 | 0 |
| `0x0A` | 设置巡航速度 | 巡航组编号 | 速度 | 0 |
| `0x0B` | 设置巡航留停时间 | 巡航组编号 | 时间(秒) | 0 |
| `0x0C` | 添加巡航点 | 巡航组编号 | 预置位编号 | 0 |
| `0x0D` | 删除巡航点 | 巡航组编号 | 预置位编号 | 0 |
| `0x15` | 开始自动扫描 | 扫描组 | 0 | 0 |
| `0x16` | 停止自动扫描 | 扫描组 | 0 | 0 |
| `0x17` | 设置左边界 | 扫描组 | 0 | 0 |
| `0x18` | 设置右边界 | 扫描组 | 0 | 0 |
| `0x19` | 设置扫描速度 | 扫描组 | 速度 | 0 |
| `0x21` | 雨刷开 | 0 | 0 | 0 |
| `0x22` | 雨刷关 | 0 | 0 | 0 |
| `0x40` | 辅助开关开 | 开关ID | 0 | 0 |
| `0x41` | 辅助开关关 | 开关ID | 0 | 0 |
| `0x44` | 光圈开大 | 速度 | 0 | 0 |
| `0x45` | 光圈缩小 | 速度 | 0 | 0 |
| `0x42` | 聚焦拉近 | 速度 | 0 | 0 |
| `0x43` | 聚焦推远 | 速度 | 0 | 0 |

## 7. 设备控制指令集

所有指令通过 `SIP MESSAGE` 发送，`CmdType=DeviceControl`

### 7.1 远程重启

```xml
<?xml version="1.0" encoding="GB2312"?>
<Control>
  <CmdType>DeviceControl</CmdType>
  <SN>123456</SN>
  <DeviceID>34020000001320000001</DeviceID>
  <TeleBoot>Boot</TeleBoot>
</Control>
```

### 7.2 录像控制

```xml
<Control>
  <CmdType>DeviceControl</CmdType>
  <SN>123456</SN>
  <DeviceID>34020000001310000001</DeviceID>
  <RecordCmd>Record</RecordCmd>   <!-- 或 StopRecord -->
</Control>
```

### 7.3 布防/撤防

```xml
<Control>
  <CmdType>DeviceControl</CmdType>
  <SN>123456</SN>
  <DeviceID>34020000001320000001</DeviceID>
  <GuardCmd>SetGuard</GuardCmd>   <!-- 或 ResetGuard -->
</Control>
```

### 7.4 报警复位

```xml
<Control>
  <CmdType>DeviceControl</CmdType>
  <SN>123456</SN>
  <DeviceID>34020000001320000001</DeviceID>
  <AlarmCmd>ResetAlarm</AlarmCmd>
  <Info>
    <AlarmMethod>2</AlarmMethod>  <!-- 可选，报警方式 -->
    <AlarmType>1</AlarmType>      <!-- 可选，报警类型 -->
  </Info>
</Control>
```

### 7.5 强制关键帧（IDR帧）

```xml
<Control>
  <CmdType>DeviceControl</CmdType>
  <SN>123456</SN>
  <DeviceID>34020000001310000001</DeviceID>
  <IFameCmd>Send</IFameCmd>
</Control>
```

### 7.6 看守位（HomePosition）

```xml
<!-- 开启看守位 -->
<Control>
  <CmdType>DeviceControl</CmdType>
  <SN>123456</SN>
  <DeviceID>34020000001310000001</DeviceID>
  <HomePosition>
    <Enabled>1</Enabled>
    <ResetTime>60</ResetTime>     <!-- 自动归位间隔秒 -->
    <PresetIndex>1</PresetIndex>  <!-- 归位到哪个预置位 -->
  </HomePosition>
</Control>

<!-- 关闭看守位 -->
<HomePosition>
  <Enabled>0</Enabled>
</HomePosition>
```

### 7.7 拖拽变倍（DragZoom）

```xml
<!-- 放大框选区域 -->
<Control>
  <CmdType>DeviceControl</CmdType>
  <SN>123456</SN>
  <DeviceID>34020000001310000001</DeviceID>
  <DragZoomIn>
    <Length>1920</Length>         <!-- 图像宽度 -->
    <Width>1080</Width>           <!-- 图像高度 -->
    <MidPointX>960</MidPointX>    <!-- 框选中心X -->
    <MidPointY>540</MidPointY>    <!-- 框选中心Y -->
    <LengthX>400</LengthX>        <!-- 框选宽度 -->
    <LengthY>300</LengthY>        <!-- 框选高度 -->
  </DragZoomIn>
</Control>

<!-- 缩小：<DragZoomOut>...</DragZoomOut> 结构相同 -->
```

### 7.8 设备基础参数配置

```xml
<Control>
  <CmdType>DeviceConfig</CmdType>
  <SN>123456</SN>
  <DeviceID>34020000001320000001</DeviceID>
  <BasicParam>
    <Name>Camera-01</Name>          <!-- 可选 -->
    <Expiration>3600</Expiration>   <!-- 注册有效期，可选 -->
    <HeartBeatInterval>60</HeartBeatInterval>  <!-- 可选 -->
    <HeartBeatCount>3</HeartBeatCount>         <!-- 可选 -->
  </BasicParam>
</Control>
```

## 11. 回放控制

回放控制通过 **SIP INFO** 方法发送，消息体使用 RTSP-like 格式，`Content-Type: Application/MANSRTSP`

### 11.1 暂停

```
PAUSE RTSP/1.0
CSeq: 2
PauseTime: now
```

### 11.2 恢复播放

```
PLAY RTSP/1.0
CSeq: 3
Range: npt=now-
```

### 11.3 拖动到指定位置

```
PLAY RTSP/1.0
CSeq: 4
Range: npt=3600-       ← 从第3600秒开始（相对于startTime）
```

### 11.4 倍速播放

```
PLAY RTSP/1.0
CSeq: 5
Scale: 2.0             ← 2倍速；0.5=慢速
Range: npt=now-
```

## 13. SSRC 格式规则

国标 SSRC 为 **10位十进制数字**（不是标准 RTP 的 32bit 随机数）。

### 格式定义

```
位：[0][1234][56789]
     ↑   ↑      ↑
    类型  域ID   序列号
```

| 首位 | 含义 |
|------|------|
| `0` | 实时直播流 |
| `1` | 历史回放/下载流 |

**示例：**
```
0100000001  → 实时流，域ID=1000，序列=00001
1100000001  → 回放流，域ID=1000，序列=00001
```

### WVP 中的 SSRC 生成逻辑

- 从配置文件读取"平台 SIP ID"的第3~6位作为域码（4位）
- 序列号从Redis中持续自增，保证唯一
- 格式化为 10 位字符串（不足补0）

### 多端口模式 vs 单端口模式

| 模式 | 说明 |
|------|------|
| 多端口（rtpEnable=true） | 每路流独立端口，ssrc 可任意 |
| 单端口 | 所有流共用一个端口，靠 SSRC 区分不同设备流 |

## 14. 截图实现逻辑

**GB28181 标准中没有定义截图命令**。WVP 的实现方案：

### 方案：视频流截帧

```
1. 检查目标通道是否已在点播中
2. 若已点播：
   直接从 ZLM/FFmpeg 抓取当前帧
   调用接口参数：url=rtsp://[媒体服务器]/rtp/[streamId]
3. 若未点播：
   a. 发起 INVITE，等待流建立
   b. 成功后调 ZLM 截图接口
   c. 截图完成后，视配置决定是否停止点播
4. 截图保存路径：snap/{deviceId}_{channelId}.jpg
```

### ZLM getSnap 接口参数（仅供参考）

```
GET /index/api/getSnap?
  url=rtsp://127.0.0.1:10554/rtp/34020000001320000001_34020000001310000001
  &timeout_sec=15
  &expire_sec=1
  &async=1
```

返回：JPEG 二进制数据

### 注意事项

- 截图质量取决于当前帧质量，建议先强制设备发一个 IDR 帧（`IFameCmd:Send`）再截图
- 部分设备 P 帧累积后才出图，截图时机很重要

## 附录：SIP 消息发送顺序规则

| 场景 | 方法 | 响应等待 |
|------|------|----------|
| 目录查询 | MESSAGE(Query) | 多条 MESSAGE(Response) |
| 设备控制（PTZ等） | MESSAGE(Control) | 200 OK 即可（无响应XML） |
| 录像控制、布防等 | MESSAGE(Control) | XML Response，有 SN 对应 |
| 开始点播 | INVITE | 200 OK(SDP) → 发 ACK |
| 停止点播 | BYE | 200 OK |
| 回放控制 | INFO | 200 OK |
| 语音广播通知 | MESSAGE(Notify) | 设备主动 INVITE（反向） |

## 附录：国标设备ID分类（第11~13位）

| 类型码范围 | 含义 |
|-----------|------|
| 000 | 其他设备 |
| 111~119 | NVR/DVR |
| 131~139 | 摄像头（IPC） |
| 132 | 枪式摄像机 |
| 136 | 半球摄像机 |
| 137 | 球机 |
| 200 | 报警设备 |
| 215 | 声音探测器 |
| 216 | 入侵探测器 |

**判断是否前端外围设备（WVP 逻辑）：**
```
typeCode = parseInt(deviceId.substring(10, 13))
isFrontEnd = typeCode > 130 && typeCode < 199
```
